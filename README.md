зробила сцену MainScene, додала персонажа зі спрайта PlayerCharacter і скрипт PlayerController. підлогу намалювала із двох плиток, налаштувала MoveAction зі стрілками та WASD і додала стік геймпада. рух зробила через Time.deltaTime, швидкість 3 одиниці за секунду спершу між плитками були щілини, поміняла Pixels Per Unit = 64, а Order in Layer = -10, щоб підлога малювалася під персонажем. зрозуміла, що Update викликається щокадру, а Time.deltaTime це час від попереднього кадру, тож множення на нього перетворює рух «за кадр» на «за секунду». без нього на повільному комп'ютері з меншим fps персонаж ішов би повільніше, ніж на швидкому
